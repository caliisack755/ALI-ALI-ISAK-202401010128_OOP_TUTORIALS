Week 1:  Getting Started with Codespaces

Weeks 3–4: People Management

3. Challenges Encountered
One of the main challenges I encountered was understanding Java syntax and the relationship between different classes. At several points, I experienced compilation errors because of incorrect class names, file names, missing classes, or incorrect commands.
Another challenge was understanding inheritance and abstraction. Initially, concepts such as extends, super(), protected, and abstract were confusing. File handling in Weeks 8–9 was also challenging because it required understanding exceptions and different classes for reading and writing files.
Working with GitHub and Codespaces also presented some difficulties, especially when compiling files from the wrong directory or pushing changes to the repository.
4. How the Challenges Were Overcome
I overcame these challenges by carefully reading compiler error messages and checking the files and directories in the terminal. Commands such as ls, cd, git status, and javac helped me identify and solve many problems.
I also improved my understanding by breaking larger problems into smaller sections and testing each part of the program separately. For example, when working with inheritance, I first understood the parent class before implementing the child class.
Repeated practice also helped me become more comfortable with Git and GitHub. I learned to follow a consistent workflow of checking the status, adding changes, committing them, and pushing them to the repository.
5. Improvements in Java Programming Skills
My Java programming skills improved significantly throughout the tutorials. I became more confident in writing classes, creating objects, defining constructors, and implementing methods. I also improved my ability to identify syntax and compilation errors.
In addition, I gained practical experience with Java collections, file handling, exception handling, inheritance, and GUI programming. I am now more comfortable reading Java code and understanding how different classes interact within a program.
6. Understanding of Object-Oriented Programming Concepts
The tutorials helped me understand the four major principles of OOP:
•	Encapsulation: protecting data using private attributes and providing controlled access through getters and setters.
•	Inheritance: allowing a child class to inherit properties and methods from a parent class.
•	Polymorphism:  allowing the same method to behave differently depending on the object.
•	Abstraction: hiding implementation details and exposing only the necessary functionality.
Before completing these tutorials, these concepts were mainly theoretical to me. The practical exercises helped me understand how they are actually implemented in Java applications.
