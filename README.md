## 9. How to Run the Projects

### Step 1: Clone the Repository

```bash
git clone <repository-url>
cd object-oriented-programming-tutorials
```

### Step 2: Navigate to a Tutorial

For example:

```bash
cd tutorial_2
```

### Step 3: Compile the Java Files

```bash
javac Main.java Student.java
```

### Step 4: Run the Program

```bash
java Main
```

For tutorials containing multiple Java classes, compile all required `.java` files before running the main class.

For example:

```bash
cd week_7
javac Appliance.java WashingMachine.java Refrigerator.java Main.java
java Main
```

For Week 10:

```bash
cd week_10
javac Questions.java QuizBattleGUI.java
java QuizBattleGUI
```
